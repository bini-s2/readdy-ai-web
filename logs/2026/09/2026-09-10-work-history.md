## 콘텐츠 구성

- 업종별 사이트 예시를 최소 3개 포함하는 가이드를 기준으로 비교형 포스팅을 구성했다.
- 뷰티살롱·에스테틱을 메인 사례로 깊게 다루고 카페·학원/온라인 강좌는 가벼운 예시로 보여주는 방향을 정했다.
- 캡처·GIF 시연과 편집 과정을 담는 구성을 검토했다.

## 업종별 시안과 프롬프트 방향

| 사례 | 대화에서 정리한 방향 |
| --- | --- |
| 카페 | 가을·겨울 분위기와 교토 감성의 시안·프롬프트 검토 |
| 뷰티 | BINI 브랜드명, Gentle Monster·Vogue를 참고한 비주얼 톤, 메인 사례 고도화 |
| 학원·온라인 강좌 | 업종별 비교를 위한 사이트 예시와 프롬프트 요청 |

프롬프트의 정확한 원문과 최종 적용본은 이 기록에 복원하지 않았다. 위 표는 당시의 의도와 검토 방향이다.

## 수정하며 확인한 문제

- 프롬프트 수정 과정에서 텍스트·서체 표현을 다시 점검해야 하는 문제가 있었다.
- 사이트의 시각적 스타일과 텍스트 내용의 업종·맥락이 맞는지 검토했다.
- 원하는 배치와 콘텐츠가 생성 결과에 반영되는지 캡처로 확인하며 재수정을 요청했다.
- 배경 이미지 입력과 소복이의 던지기·줍기 인터랙션 아이디어도 대화에 남아 있으나, 구현 완료로 확정하지 않는다.

## 콘텐츠 제작 준비

- 시안 3개를 비교할 GIF와 메인 시안 1개의 고도화를 구상했다.
- 로고 3개 중 하나를 넣는 블로그 썸네일 4안 제작을 요청했다.
- 블로그 초안 구성과 예시 배치를 논의했다.

## 아직 확정하지 않은 상태

- 업종별 최종 배포 URL과 최종 선택된 시안
- 원문 프롬프트 및 실제 적용 순서
- GIF·썸네일 전체 결과물의 최종 확정 여부
- 블로그 초안 제출과 최종 발행 완료 여부

근거: Readdy 협업·시안 검토·프롬프트·썸네일 작업 대화. 이번 정리는 작업 기록이며, Readdy 편집기나 실제 사이트를 수정한 것은 아니다.
