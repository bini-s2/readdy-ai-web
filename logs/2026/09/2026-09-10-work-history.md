## 업종 3종 비교 콘텐츠

- 업종별 사이트 예시를 최소 3개 포함하는 가이드를 기준으로 비교형 포스팅을 구성했습니다.
- 뷰티살롱·에스테틱을 메인 사례로 깊게 다루고 카페·학원/온라인 강좌는 가벼운 예시로 보여주는 방향을 정했습니다.
- 캡처·GIF 시연과 편집 과정을 담는 구성을 검토했습니다.

### 업종별 시안과 프롬프트 방향

| 사례 | 대화에서 정리한 방향 |
| --- | --- |
| 카페 | 가을·겨울 분위기와 교토 감성의 시안·프롬프트 검토 |

## BINI OFFICE

[BINI OFFICE 프로젝트 기록 →](../../../projects/bini-office.md)

- 소복이네 캐릭터와 사용자를 모티브로 만든 BINI 인물 캐릭터를 하나의 오피스 공간에 배치했습니다.
- 옐로우·화이트 중심의 아이소메트릭 사무실 배경, 두 캐릭터가 함께 있는 장면, 소복이 단독 장면을 사용자가 제공한 이미지로 확인했습니다.
- 캐릭터가 없는 사무실 배경을 별도로 두고 캐릭터와 UI 요소를 결합하는 구성도 확인했습니다.
- 배경 이미지 입력과 소복이의 던지기·줍기 인터랙션 아이디어는 대화에 남아 있으나 실제 구현 완료 범위는 확정하지 않습니다.

## 별도 패션 웹 — BINI 26FW / OFF HOURS

[BINI Fashion 프로젝트 기록 →](../../../projects/bini-fashion.md)

패션 웹은 업종 3종 비교 사례 중 하나가 아니라 **별도로 진행한 추가 프로젝트**입니다.

- 브랜드명: `BINI`
- 시즌 콘셉트: `26FW / OFF HOURS`
- 방향: Contemporary · Urban · Minimal · Editorial
- 주요 톤: Black · Off-white · Charcoal · Stone gray · Silver
- 구성: Hero / About Brand / Seasonal Collection / Lookbook / Featured Pieces / Campaign · Editorial / Store Information / Contact
- 초기의 어두운 도시적 하이패션 이미지에서, 구조는 유지하면서 더 clean · sculptural · refined한 여성 패션·에디토리얼 이미지 방향으로 수정했습니다.
- `off-white`는 브랜드명이 아닌 색상 의미로 사용했습니다.
- Gothic · Punk · Streetwear 쪽으로 치우치는 이미지는 제외하는 방향으로 정리했습니다.

## 수정하며 확인한 문제

- 프롬프트 수정 과정에서 텍스트·서체 표현을 다시 점검해야 하는 문제가 있었습니다.
- 사이트의 시각적 스타일과 텍스트 내용의 업종·맥락이 맞는지 검토했습니다.
- 원하는 배치와 콘텐츠가 생성 결과에 반영되는지 캡처로 확인하며 재수정을 요청했습니다.

## 콘텐츠 제작 준비

- 업종 3종 시안을 비교할 GIF와 메인 시안 1개의 고도화를 구상했습니다.
- 로고 3개 중 하나를 넣는 블로그 썸네일 4안 제작을 요청했습니다.
- 블로그 초안 구성과 예시 배치를 논의했습니다.

## 아직 확정하지 않은 상태

- 각 프로젝트의 최종 배포 URL과 최종 선택 시안
- 원문 프롬프트 및 실제 적용 순서
- GIF·썸네일 전체 결과물의 최종 확정 여부
- 블로그 초안 제출과 최종 발행 완료 여부
- BINI OFFICE 인터랙션의 실제 구현 범위

근거: Readdy 협업·시안 검토·프롬프트·캐릭터/공간 구성·패션 웹 작업 대화와 사용자가 제공한 작업 이미지. 이번 정리는 작업 기록이며, Readdy 편집기 자체를 수정한 것은 아닙니다.
